<h2 align="center">💼 What I Do</h2>

- 🏢 **Spring 기반 백오피스 서비스 개발·운영** — Java/Spring으로 사내 운영 도구를 만들고, Oracle·PostgreSQL을 다뤄요
- 🔥 **장애 대응과 개선** — 대용량 조회로 WAS가 멈췄던 경험을 계기로, 전체 조회(selectList) 대신 커서 스트리밍 처리로 메모리 문제를 개선하는 방법을 연구했어요 → [`save-the-was`](https://github.com/orisjineman/save-the-was)
- 🚢 **배포와 인프라** — Docker·Nginx·Jenkins 기반 배포 환경을 다루고, 헬스체크·롤링 배포를 로컬에서 직접 실험해요 → [`infra-lab`](https://github.com/orisjineman/infra-lab)
